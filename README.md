# LJT-Homepage

Personal academic homepage of **Junteng Liu**, first-year Ph.D. candidate in the [HKUST NLP Group](https://github.com/hkust-nlp) at the Hong Kong University of Science and Technology (HKUST).

## Site contents

This site is built with the [Academic Pages template](https://github.com/academicpages/academicpages.github.io) forked from [academicpages/academicpages.github.io](https://github.com/academicpages/academicpages.github.io), and contains:

- **About** (home page): personal details, academic background, research experience, skills and research interests, publications, honors and awards, and contact information. Content: [`_pages/about.md`](_pages/about.md).
- **Publications**: full publication list. Page: [`_pages/publications.html`](_pages/publications.html); one Markdown record per paper in [`_publications/`](_publications/).

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open <http://localhost:4000/LJT-Homepage/>.
